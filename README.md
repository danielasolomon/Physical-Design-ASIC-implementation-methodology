# Physical-Design-ASIC-implementation-methodology
Implemented a complete ASIC physical design flow (14nm technology) using  Synopsys Fusion Compiler

Performed RTL code conversion (including memory adaptation and I/O pad insertion), followed by logic synthesis, including the creation of SDC and UPF constraint files. Completed all major steps of the flow: floorplanning, standard cell placement, clock tree synthesis (CTS), and routing, with automation via custom TCL scripts.

Achieved a low-area (~1 mm²), power-efficient SoC design. Covered all key phases: Pre-PnR, PnR, and Post-PnR.
